# 리플레이

## 개요

과거 특정 날짜의 차량 운행 기록을 재생할 수 있는 기능입니다.
날짜·지역·차량 조건으로 기록을 검색하고, 원하는 구간을 선택해 지도 위에서 재생할 수 있습니다.

---

## 진입 방법

![리플레이 아이콘](images/replay/entry-button.png)

좌측 사이드바에서 **리플레이 아이콘**을 클릭합니다. 같은 아이콘을 다시 클릭하면 패널이 닫힙니다.

---

## 화면 구성

리플레이는 **기록 검색**과 **재생** 두 단계로 진행됩니다.

---

## 1단계 — 기록 검색

### 필터

![검색 필터](images/replay/search-filter.png)

| 필터 항목 | 설명                                          |
| --------- | --------------------------------------------- |
| 날짜      | 조회할 날짜를 하루 단위로 선택 (기본값: 오늘) |
| 지역      | 특정 지역의 기록만 조회                       |
| 차량      | 특정 차량의 기록만 조회                       |

필터 조건을 변경하면 즉시 자동 검색됩니다.

### 기록 목록

![기록 목록](images/replay/record-list.png)

검색 결과로 해당 날짜의 운행 기록 구간 목록이 표시됩니다.

| 열                   | 내용                          |
| -------------------- | ----------------------------- |
| <nobr>날짜</nobr>    | 운행 구간의 시작 날짜 및 시각 |
| <nobr>차량 수</nobr> | 해당 구간에 포함된 차량 수    |
| <nobr>차량명</nobr>  | 구간에 포함된 차량 이름 목록  |

행을 클릭하면 해당 구간의 재생 화면으로 전환됩니다. 기록이 없는 경우 목록이 비어 있습니다.

---

## 2단계 — 재생

![리플레이 재생 화면](images/replay/playback-map.png)

구간을 선택하면 재생 화면으로 전환되며, 지도 위에서 차량의 과거 경로를 재생합니다.

### 재생 컨트롤

![재생 컨트롤](images/replay/player-controls.png)

| 컨트롤                        | 설명                                                                        |
| ----------------------------- | --------------------------------------------------------------------------- |
| <nobr>재생 / 일시정지</nobr>  | 재생과 일시정지를 전환합니다                                                |
| <nobr>이전 구간</nobr>        | 목록에서 이전 운행 구간으로 이동합니다                                      |
| <nobr>다음 구간</nobr>        | 목록에서 다음 운행 구간으로 이동합니다                                      |
| <nobr>슬라이더</nobr>         | 드래그하여 재생 시점을 자유롭게 변경합니다                                  |
| <nobr>현재 시각</nobr>        | 현재 재생 중인 시점의 날짜와 시각 (YYYY-MM-DD HH:mm:ss 형식)                |
| <nobr>경과 / 남은 시간</nobr> | 구간 시작부터 현재까지의 경과 시간과 구간 종료까지의 남은 시간을 표시합니다 |
