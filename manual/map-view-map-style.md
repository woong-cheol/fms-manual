# 지도 스타일

## 개요

지도의 배경 스타일, NaviLink 도로 색상 기준, 차량 아이콘 의미를 설정하고 확인할 수 있습니다.

---

## 지도 타입

![지도 타입 팝오버](images/map-view/map-type-popover.png)

각 지도 화면 우측의 **지도 타입 버튼**을 클릭하면 지도 배경 스타일을 선택하는 팝오버가 열립니다.

| 스타일 | 설명                                                                                |
| ------ | ----------------------------------------------------------------------------------- |
| Light  | 밝은 배경의 기본 지도 스타일                                                        |
| Dark   | 어두운 배경의 지도 스타일                                                           |
| Lidar  | 라이다 센서로 취득한 고정밀 지도. 해당 지역에 라이다 맵이 등록된 경우에만 선택 가능 |

선택한 스타일은 해당 지도 화면에 즉시 적용됩니다.

![지도 타입 변경 예시 — Light](images/map-view/map-type-light.png)

## 라인 타입

![라인 타입 팝오버](images/map-view/line-type-popover.png)

각 지도 화면 우측의 **라인 타입 버튼**을 클릭하면 NaviLink 도로 선의 색상 기준을 선택할 수 있습니다.

지역이 선택된 경우에만 활성화됩니다.

| 기준                  | 설명                                                                          |
| --------------------- | ----------------------------------------------------------------------------- |
| <nobr>주행거리</nobr> | 도로 구간별 누적 주행거리에 따라 색상 구분                                    |
| <nobr>주행속도</nobr> | 도로 구간별 주행속도에 따라 색상 구분                                         |
| 차선                  | 차선 정보에 따라 색상 구분. 횡단보도·어린이 보호구역이 지도에 함께 표시됩니다 |

![라인 타입 — 주행거리](images/map-view/line-type-mileage.png)

![라인 타입 — 주행속도](images/map-view/line-type-speed.png)

![라인 타입 — 차선](images/map-view/line-type-lane.png)

## NaviLink 설정

![NaviLink 설정 — 주행거리 탭](images/map-view/navilink-mileage.png)

하단 고정 영역의 **NaviLink 버튼**을 클릭하면 지도에 표시되는 NaviLink 도로 라인의 색상 기준값과 범례를 확인하고 조정할 수 있습니다.

라인 타입이 **주행거리** 또는 **주행속도**로 설정된 경우, 각 도로 구간의 실측값이 최대 기준값 대비 몇 %인지에 따라 6단계 색상으로 구분되어 지도에 표시됩니다.

| 탭                    | <nobr>기준값 범위</nobr> | 설명                                            |
| --------------------- | ------------------------ | ----------------------------------------------- |
| <nobr>주행거리</nobr> | 1 ~ 500 km               | 슬라이더나 입력 필드로 최대 기준값을 조정합니다 |
| <nobr>주행속도</nobr> | 1 ~ 100 km/h             | 슬라이더나 입력 필드로 최대 기준값을 조정합니다 |

팝오버 오른쪽에 현재 기준에 맞는 색상 범례가 표시됩니다. 최대 기준값을 변경하면 각 구간의 실제 수치가 즉시 재계산되어 범례와 지도 라인 색상이 함께 업데이트됩니다.

| 색상 구간 | 의미                               |
| --------- | ---------------------------------- |
| 100%      | 최대 기준값 이상                   |
| 80% ~     | 최대 기준값의 80% 이상             |
| 60% ~     | 최대 기준값의 60% 이상             |
| 40% ~     | 최대 기준값의 40% 이상             |
| 20% ~     | 최대 기준값의 20% 이상             |
| 0% ~      | 최대 기준값의 20% 미만 (가장 낮음) |

예를 들어 주행거리 최대 기준값을 100 km로 설정하면, 80 km 이상 구간은 80% 색상, 40 km 이상 구간은 40% 색상으로 표시됩니다.

![NaviLink 설정 — 주행속도 탭](images/map-view/navilink-speed.png)

## 차량 범례

하단 고정 영역의 **차량 범례 버튼**을 클릭하면 지도에 표시되는 차량 아이콘의 색상 의미를 확인할 수 있습니다.

| 아이콘                   | 의미                                      |
| ------------------------ | ----------------------------------------- |
| <nobr>민트색 차량</nobr> | <nobr>자율주행(Auto Mode) ON 상태</nobr>  |
| <nobr>기본색 차량</nobr> | <nobr>자율주행(Auto Mode) OFF 상태</nobr> |

차량 범례는 지도 화면 우측 하단에도 항상 고정 표시됩니다.
