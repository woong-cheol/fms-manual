# 원격운전

## 개요

원격 제어가 가능한 차량 목록을 실시간으로 확인하고, 제어 가능 상태의 차량에 원격 모니터링을 시작할 수 있는 기능입니다.

---

## 진입 방법

좌측 사이드바에서 **원격제어 아이콘**을 클릭합니다.

![원격제어 아이콘](images/teleoperation/entry-button.png)

같은 아이콘을 다시 클릭하면 패널이 닫힙니다.

---

## 차량 목록

원격 제어 대상 차량 목록이 실시간으로 표시됩니다.
자신에게 접근 권한이 부여된 차량만 목록에 나타납니다.

![차량 목록](images/teleoperation/vehicle-list.png)

| 열        | 내용                          |
| --------- | ----------------------------- |
| 지역      | 차량이 운행 중인 지역         |
| 차량명    | 차량 이름                     |
| 차량 상태 | 차량의 현재 주행 상태         |
| 원격 제어 | 원격 제어 연결 가능 여부 상태 |
| 제어      | 원격 모니터링 시작 버튼       |

---

## 차량 상태

| 상태       | 설명                  |
| ---------- | --------------------- |
| 자율 주행  | 자율주행 중           |
| 수동 주행  | 운전자가 직접 운전 중 |
| 원격 주행  | 원격 제어 중          |
| 비상 정지  | 비상 정지 상태        |
| 충전 중    | 충전 중               |
| 진단 중    | 엔지니어링·진단 모드  |
| 알 수 없음 | 상태 정보 없음        |

---

## 원격 제어 상태

| 상태      | 설명                                 |
| --------- | ------------------------------------ |
| 제어 가능 | 원격 제어 연결을 시작할 수 있는 상태 |
| 제어 불가 | 원격 제어 연결이 불가능한 상태       |
| 연결 중   | 콕핏과 연결 시도 중                  |
| 연결됨    | 콕핏과 연결 완료                     |
| 연결 종료 | 연결이 종료된 상태                   |
| 연결 실패 | 연결 시도에 실패한 상태              |
| 오프라인  | 차량 TCU가 오프라인 상태             |

---

## 원격 모니터링 시작

**원격 제어 상태가 "제어 가능"인 차량**에 한해 제어 버튼이 활성화됩니다.

![제어 버튼](images/teleoperation/control-button.png)

제어 버튼(리모컨 아이콘)을 클릭하면 해당 차량의 **원격 모니터링 모달**이 열립니다.

![원격 모니터링 모달](images/teleoperation/monitoring-modal.png)

### 모달 구성

모달은 세 영역으로 구성됩니다.

| 영역                   | 설명                                                                  |
| ---------------------- | --------------------------------------------------------------------- |
| <nobr>차량 선택</nobr> | 모니터링할 차량을 선택합니다. 목록에는 제어 가능한 차량만 표시됩니다. |
| <nobr>영상 설정</nobr> | 스트리밍 영상의 해상도·카메라 채널 등 영상 관련 옵션을 설정합니다.    |
| <nobr>원격 운전</nobr> | 차량 영상을 확인하고 원격 조작을 수행합니다.                          |
