# 차량 운행 상태

## 개요

현재 운행 중인 차량과 대기 중인 차량의 상태를 실시간으로 확인할 수 있는 패널입니다.
차량의 위치, 운행 현황, 시스템 오류 여부를 한눈에 파악할 수 있습니다.

---

## 진입 방법

![차량 아이콘](images/vehicle-status/entry-button.png)

좌측 사이드바에서 **차량 아이콘**을 클릭합니다. 같은 아이콘을 다시 클릭하면 패널이 닫힙니다.

---

## 화면 구성

패널은 두 개의 탭으로 구성됩니다.

| 탭            | 설명                                  |
| ------------- | ------------------------------------- |
| 운행중 차량   | 현재 운행 중인 차량 목록 및 요약 현황 |
| 운행종료 차량 | 현재 대기 중인 차량 목록              |

---

## 운행중 차량 탭

### 지역 필터

![지역 필터](images/vehicle-status/region-filter.png)

목록 상단의 지역 필터를 사용해 특정 지역의 차량만 조회할 수 있습니다.
선택하지 않으면 전체 지역의 운행 차량이 표시됩니다.

### 요약 카드

![요약 카드](images/vehicle-status/summary-cards.png)

지역 필터 아래에 두 개의 요약 카드가 표시됩니다.

| 카드             | 내용                                         |
| ---------------- | -------------------------------------------- |
| 주행 중인 차량   | 현재 운행 중인 차량 수 / 전체 서비스 차량 수 |
| 금일 총 주행거리 | 오늘 하루 누적 주행거리 (km)                 |

### 차량 목록

![운행중 차량 목록](images/vehicle-status/online-vehicle-list.png)

요약 카드 아래에 운행 중인 차량 목록이 표시됩니다.

| 열                         | 내용                       |
| -------------------------- | -------------------------- |
| <nobr>지역</nobr>          | 차량이 운행 중인 지역 이름 |
| <nobr>차량명</nobr>        | 차량 이름                  |
| <nobr>속도</nobr>          | 현재 주행 속도 (km/h)      |
| <nobr>오늘 주행거리</nobr> | 오늘 누적 주행거리 (km)    |
| <nobr>카메라</nobr>        | 차량 카메라 스트리밍 버튼  |

#### 행 클릭 동작

행을 클릭하면 지도가 해당 차량으로 이동하며 차량 추적이 활성화됩니다. 이미 해당 차량을 추적 중인 경우 다시 클릭하면 추적이 해제됩니다. 자세한 내용은 [차량 추적](/manual/map-view-auto-tracking)을 참고하세요.

#### 카메라 버튼

![카메라 버튼 상태 비교](images/vehicle-status/camera-button-states.png)

| 조건                                  | 동작                                                         |
| ------------------------------------- | ------------------------------------------------------------ |
| TCU 미장착 차량                       | 버튼이 비활성화되어 클릭할 수 없습니다                       |
| <nobr>TCU 장착 + 스트리밍 가능</nobr> | 버튼 클릭 시 실시간 영상 스트리밍 화면이 열립니다            |
| <nobr>TCU 장착 + 스트리밍 불가</nobr> | 버튼 클릭 시 스트리밍을 사용할 수 없다는 메시지가 표시됩니다 |

## 운행종료 차량 탭

![운행종료 차량 목록](images/vehicle-status/offline-vehicle-list.png)

현재 운행하지 않고 대기 중인 차량 목록을 보여줍니다.

| 열                            | 내용                                |
| ----------------------------- | ----------------------------------- |
| <nobr>지역</nobr>             | 차량이 마지막으로 운행한 지역 이름  |
| <nobr>차량명</nobr>           | 차량 이름                           |
| <nobr>마지막 운행 시각</nobr> | 가장 최근 운행이 종료된 날짜와 시각 |

행을 클릭하면 지도가 해당 차량의 마지막 위치가 있는 지역으로 이동합니다.
