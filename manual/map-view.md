# 지도 화면

![지도 화면 전체](images/map-view/overview.png)

## 화면 분할

지도 화면은 하나 또는 여러 개의 지도를 동시에 표시할 수 있습니다. 우측 상단의 **뷰 버튼**으로 분할 방식을 선택합니다. 자세한 내용은 [화면 분할](/manual/map-view-screen-split)을 참고하세요.

## 지역 선택

![지역 선택 버튼](images/map-view/region-select-button.png)

각 지도 화면 **좌측 상단**에 지역 선택 버튼이 표시됩니다. 버튼을 클릭하면 팝오버가 열립니다.

| 버튼 표시 | 상태                         |
| --------- | ---------------------------- |
| 지역 선택 | 아직 선택하지 않은 초기 상태 |
| 전체 지역 | 전체 지역으로 설정된 상태    |
| 지역명    | 특정 지역이 선택된 상태      |

### 팝오버 구성

![지역 선택 팝오버](images/map-view/region-select-popover.png)

- **검색 필드**: 지역명으로 검색합니다.
- **최근 선택**: 최근에 선택한 지역을 칩 형태로 최대 5개까지 표시합니다. 검색 중에는 숨겨집니다.
- **지역 목록**: 전체 지역과 개별 지역을 라디오 버튼으로 선택합니다. 가나다순으로 정렬됩니다.
- **하단 정보**: 전체 지역 수와 검색 결과 수를 표시합니다.

지역을 선택하면 팝오버가 닫히고 선택한 지역이 즉시 적용됩니다. 지역이 선택된 경우 지도 스타일(라인 타입)과 지도 레이어(코스·공사구간·LDM) 버튼이 활성화됩니다.

## 차량 아이콘

![차량 아이콘](images/map-view/vehicle-icons.png)

지도 위에 표시되는 차량 아이콘은 색상으로 자율주행 상태를 나타냅니다.

| 아이콘 색상 | 의미                         |
| ----------- | ---------------------------- |
| 민트색      | 자율주행(Auto Mode) ON 상태  |
| 기본색      | 자율주행(Auto Mode) OFF 상태 |

색상 범례는 지도 화면 우측 하단에 항상 고정 표시됩니다.

## 하단 티커

![하단 티커](images/map-view/ticker.png)

화면 맨 아래에 고정된 알림 표시줄입니다. 차량 운행·이벤트·원격제어와 관련된 알림이 실시간으로 표시됩니다.

각 항목은 `[HH:mm:ss.SSS]` 형식의 발생 시각, 타입 배지, 제목, 설명으로 구성됩니다.

| 타입   | 색상 | 발생 조건                                 |
| ------ | ---- | ----------------------------------------- |
| FLEET  | 초록 | 차량 운행 시작 / 종료                     |
| EVENT  | 주황 | AEB·공사구간 등 차량 이벤트 발생          |
| CMD    | 주황 | 원격 명령 요청 발생                       |
| TOD    | 주황 | 원격제어 시작 / 종료 (TCU·콕핏 연결 변경) |
| SYSTEM | 파랑 | 시스템 알림                               |
| SAFETY | 빨강 | 안전 관련 알림                            |

가장 최신 항목이 메인 라인에 점멸 아이콘과 함께 표시됩니다. 티커 영역을 클릭하면 최근 100건의 이력 목록이 펼쳐지며, 이력이 없으면 빈 상태 메시지가 표시됩니다.

![티커 이력 목록](images/map-view/ticker-history.png)

**EVENT 타입** 항목을 클릭하면 해당 이벤트가 발생한 위치로 지도가 이동하고 이벤트 상세 오버레이가 표시됩니다.

## 지도 스타일

지도 배경, 차량 아이콘 색상, NaviLink 도로 색상 기준을 변경합니다.

| 버튼                   | 활성화 조건  | 설명                                                 |
| ---------------------- | ------------ | ---------------------------------------------------- |
| <nobr>지도 타입</nobr> | 항상         | 지도 배경 스타일(Light / Dark / Lidar)을 선택합니다. |
| NaviLink               | 항상         | NaviLink 도로 색상 표시 여부를 설정합니다.           |
| <nobr>라인 타입</nobr> | 지역 선택 시 | NaviLink 도로 색상 기준을 선택합니다.                |

자세한 내용은 [지도 스타일](/manual/map-view-map-style)을 참고하세요.

## 자동 추적

**자동 추적 버튼**(또는 단축키 **T**)을 누르면 운행 중인 차량을 자동으로 선택해 지도가 따라갑니다. 특정 차량을 지정하지 않아도 운행 중인 차량들을 순서대로 자동 확인할 수 있습니다.

추적 중 아래 조건이 충족되면 자동으로 다른 차량으로 전환됩니다.

| 조건                        | 전환 시점                                     |
| --------------------------- | --------------------------------------------- |
| <nobr>일정 시간 경과</nobr> | 약 60초마다 다른 운행 차량으로 전환           |
| <nobr>차량 정지 감지</nobr> | 추적 중인 차량이 약 10초간 정지 상태이면 전환 |
| <nobr>운행 종료 감지</nobr> | 추적 중인 차량의 운행이 종료되면 전환         |

차량을 직접 선택해 추적하는 방법을 포함한 자세한 내용은 [차량 추적](/manual/map-view-auto-tracking)을 참고하세요.

## 지도 레이어

지역 또는 차량을 선택하면 아래 레이어 버튼이 활성화됩니다.

| 버튼                  | 활성화 조건                               | 설명                                    |
| --------------------- | ----------------------------------------- | --------------------------------------- |
| 코스                  | 지역 선택 시                              | 해당 지역의 코스를 지도에 표시합니다.   |
| <nobr>공사구간</nobr> | 지역 선택 시                              | 공사구간 표시를 켜거나 끕니다.          |
| LDM                   | 지역 선택 시                              | 동적 지도 데이터를 유형별로 표시합니다. |
| <nobr>주행경로</nobr> | <nobr>지역·차량 선택 + 데이터 존재</nobr> | 선택 차량의 주행경로를 표시합니다.      |
| 정류장                | <nobr>지역·차량 선택 + 데이터 존재</nobr> | 정류장 위치를 지도에 표시합니다.        |

자세한 내용은 [지도 레이어](/manual/map-view-map-data)를 참고하세요.

## 단축키

![단축키 팝오버](images/map-view/shortcuts-popover.png)

우측 하단의 **단축키 버튼**을 클릭하면 키보드 단축키 목록이 팝오버로 표시됩니다.

| 단축키                      | 동작                               |
| --------------------------- | ---------------------------------- |
| <nobr>← / ↑ / ↓ / →</nobr>  | 지도 이동                          |
| <nobr>+ / -</nobr>          | 지도 확대 / 축소                   |
| <nobr>Shift + 드래그</nobr> | 선택 영역 확대                     |
| R                           | 지도 위치 초기화                   |
| T                           | <nobr>자동 추적 ON/OFF 전환</nobr> |
