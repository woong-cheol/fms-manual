# 스케줄

## 개요

금일 정기노선 스케줄이 등록된 차량의 운행 현황을 실시간으로 확인할 수 있는 기능입니다.
차량별 현재 상태와 코스별 운행 시간표를 한눈에 파악할 수 있습니다.

---

## 진입 방법

좌측 사이드바에서 **스케줄 아이콘**을 클릭합니다.

![스케줄 아이콘](images/schedule/entry-button.png)

같은 아이콘을 다시 클릭하면 패널이 닫힙니다.

---

## 화면 구성

패널은 상단의 **차량 목록**과 하단의 **스케줄 상세** 두 영역으로 구성됩니다.

![스케줄 전체 화면](images/schedule/overview.png)

---

## 차량 목록

### 검색

차량 ID 또는 차량 이름으로 목록을 실시간 검색합니다.

![검색 필드](images/schedule/search.png)

### 상태 필터

상태 칩을 클릭해 특정 상태의 차량만 표시할 수 있습니다.
각 칩에는 해당 상태의 차량 수가 함께 표시됩니다.

![상태 필터](images/schedule/status-filter.png)

| 상태      | 색상 | 설명                                     |
| --------- | ---- | ---------------------------------------- |
| 전체      | —    | 모든 차량 표시                           |
| 운행중    | 초록 | 현재 스케줄에 따라 운행 중인 차량        |
| 미운행    | 빨강 | 운행 시간 중 운행하지 않는 차량          |
| 대기      | 노랑 | 다음 운행을 위해 대기 중인 차량          |
| 운행 예정 | 노랑 | 오늘 스케줄이 있으나 아직 시작 전인 차량 |
| 운행 종료 | 회색 | 오늘 스케줄이 모두 완료된 차량           |

### 차량 목록 테이블

| 열        | 내용                         |
| --------- | ---------------------------- |
| 상태 점   | 현재 상태를 색상 점으로 표시 |
| ID        | 차량 고유 ID                 |
| 차량명    | 차량 이름                    |
| 상태      | 현재 운행 상태 텍스트        |
| 운행 건수 | 오늘 배정된 총 운행 건수     |

행을 클릭하면 하단에 해당 차량의 스케줄 상세가 표시됩니다.

---

## 스케줄 상세

차량을 선택하면 하단에 해당 차량의 오늘 운행 시간표가 표시됩니다.

![스케줄 상세](images/schedule/schedule-detail.png)

| 열        | 내용                               |
| --------- | ---------------------------------- |
| 지역명    | 운행 지역 이름                     |
| 코스명    | 운행할 경로(코스) 이름             |
| 설명      | 코스 부가 설명                     |
| 시점/종점 | 출발 정류장 → 도착 정류장          |
| 운행 시간 | 출발 시각 ~ 도착 예정 시각         |
| 운행 요일 | 해당 스케줄이 운행되는 요일        |
| 사업 기간 | 스케줄 유효 기간 (시작일 ~ 종료일) |

### 현재 운행 교시 강조

현재 시각에 해당하는 운행 시간대 행은 차량 상태 색상으로 강조 표시됩니다.

- **운행중·미운행** 차량: 현재 시각이 포함된 교시 행 강조
- **대기·운행 예정** 차량: 다음 출발 예정 교시 행 강조
