# 설정

## 개요

화면 해상도, 언어, 재생 프레임 등 애플리케이션 동작 방식을 사용자 환경에 맞게 조정할 수 있습니다.
설정 값은 브라우저에 저장되어 다음 접속 시에도 유지됩니다.

---

## 진입 방법

좌측 사이드바 하단의 **설정 아이콘(⚙)** 을 클릭합니다.

![설정 아이콘](images/settings/entry-button.png)

설정 모달이 열립니다. 모달 외부를 클릭하면 닫힙니다.

---

## 설정 항목

### 보간 프레임

차량 이동 경로를 지도에 표시할 때 부드러움 정도를 조절합니다.

![보간 프레임](images/settings/interpolation-frame.png)

- 선택 가능한 값: **2 / 5 / 10 / 20 / 40 / 60 / 80 / 100 / 120**
- 값이 높을수록 경로가 더 부드럽게 표시되지만 처리 부하가 증가합니다.

---

### 화면 해상도

사용 중인 모니터 해상도에 맞는 레이아웃을 선택합니다.
대시보드와 같이 화면 크기에 따라 달라지는 UI가 올바르게 표시됩니다.

![해상도 선택](images/settings/resolution-selection.png)

| 옵션      | 해상도      | 비율 |
| --------- | ----------- | ---- |
| FHD       | 1920 × 1080 | 16:9 |
| UHD       | 3840 × 2160 | 16:9 |
| Ultrawide | 2560 × 816  | 25:8 |

---

### 언어

애플리케이션 표시 언어를 변경합니다.

![언어 설정](images/settings/language.png)

변경 즉시 적용됩니다.

---

### 화면 자동 로드

활성화하면 애플리케이션 실행 시 이전에 사용하던 화면 분할 구성(1×1 / 1×2 등)을 자동으로 불러옵니다.

![화면 자동 로드](images/settings/screen-auto-load.png)

비활성화하면 매번 기본 화면(1×1)으로 시작합니다.
