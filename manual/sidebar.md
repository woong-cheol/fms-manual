# 사이드바

화면 가장 왼쪽에 항상 고정되어 있으며, 아이콘을 클릭하면 해당 패널이 옆으로 펼쳐집니다. 같은 아이콘을 다시 클릭하면 패널이 닫힙니다.

![좌측 사이드바](images/map-view/left-sidebar.png)

| 아이콘                   | 기능                     | 비고                             |
| ------------------------ | ------------------------ | -------------------------------- |
| 사용자                   | 계정 및 사용자 관리      |                                  |
| 차량                     | 차량 운행 상태 확인      |                                  |
| 이벤트                   | 차량 이벤트 이력 조회    |                                  |
| 리플레이                 | 운행 로그 재생           |                                  |
| <nobr>데이터 추출</nobr> | 주행 데이터 추출         | <nobr>Master Company 전용</nobr> |
| 스케줄                   | 운행 스케줄 모니터링     | <nobr>Master Company 전용</nobr> |
| <nobr>원격제어</nobr>    | 원격제어 차량 목록       | <nobr>Master Company 전용</nobr> |
| 설정                     | 환경설정 (테마, 언어 등) |                                  |

사이드바 하단에는 **로그아웃 버튼**과 **현재 시각**이 표시됩니다.
