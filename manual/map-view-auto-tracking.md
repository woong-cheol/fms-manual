# 차량 추적

추적이 활성화되면 지도 화면 **하단 중앙**에 "Tracking" 레이블과 추적 중인 차량명이 표시됩니다.

![추적 중 하단 차량 정보](images/map-view-auto-tracking/tracking-vehicle-name.png)

---

## 차량 선택 추적

![온라인 차량 목록](images/map-view-auto-tracking/vehicle-list.png)

차량 운행 상태 패널의 **운행중 차량 목록**에서 차량 행을 클릭하면 지도가 해당 차량으로 이동하며 추적이 시작됩니다.

이미 추적 중인 차량 행을 다시 클릭하면 추적이 해제됩니다.

---

## 자동 추적

![자동 추적 버튼](images/map-view-auto-tracking/button.png)

특정 차량을 지정하지 않고 운행 중인 차량들을 자동으로 순환하며 추적하는 기능입니다.

### 활성화 방법

![자동 추적 활성 상태 — 차량 추적 중](images/map-view-auto-tracking/active.png)

각 지도 화면 우측의 **자동 추적 버튼**을 클릭하거나 키보드 단축키 **T** 를 누릅니다.

활성화하면 버튼이 선택 상태(강조 표시)로 바뀌고, 현재 운행 중인 차량 중 하나를 자동으로 선택해 추적을 시작합니다.

### 자동 차량 전환

추적 중 다음 조건이 충족되면 자동으로 다른 차량으로 전환됩니다.

| 조건                        | 전환 시점                                     |
| --------------------------- | --------------------------------------------- |
| <nobr>일정 시간 경과</nobr> | 약 60초마다 다른 운행 차량으로 전환           |
| <nobr>차량 정지 감지</nobr> | 추적 중인 차량이 약 10초간 정지 상태이면 전환 |
| <nobr>운행 종료 감지</nobr> | 추적 중인 차량의 운행이 종료되면 전환         |

### 비활성화 방법

![자동 추적 비활성 상태](images/map-view-auto-tracking/inactive.png)

자동 추적 버튼을 다시 클릭하거나 키보드 단축키 **T** 를 누릅니다.

비활성화하면 추적이 종료되고 지도가 현재 위치에 고정됩니다.
