# 이벤트 이력

## 개요

차량 운행 중 발생한 이벤트와 원격 명령 요청 이력을 조회할 수 있는 패널입니다.
기간·차량·지역·이벤트 유형 조건으로 필터링하고, 결과를 목록에서 확인할 수 있습니다.

---

## 진입 방법

![이벤트 아이콘](images/event-history/entry-button.png)

좌측 사이드바에서 **이벤트 아이콘**을 클릭합니다. 같은 아이콘을 다시 클릭하면 패널이 닫힙니다.

---

## 화면 구성

패널은 두 개의 탭으로 구성됩니다.

| 탭          | 설명                       |
| ----------- | -------------------------- |
| 이벤트 이력 | 차량 이벤트 발생 이력 조회 |
| 원격 명령   | 원격 명령 요청 이력 조회   |

> 해당 차량에 대한 접근 권한이 없으면 목록이 표시되지 않습니다.

---

## 이벤트 이력 탭

### 필터

![이벤트 이력 필터](images/event-history/filter.png)

| 필터 항목   | 설명                                                 |
| ----------- | ---------------------------------------------------- |
| 기간        | 시작일과 종료일을 달력으로 선택 (기본값: 최근 1개월) |
| 차량        | 특정 차량을 선택해 해당 차량의 이벤트만 조회         |
| 지역        | 특정 지역을 선택해 해당 지역의 이벤트만 조회         |
| 이벤트 유형 | 조회할 이벤트 유형을 선택                            |

필터 조건을 변경하면 목록이 자동으로 갱신됩니다.

#### 이벤트 유형

| 유형         | 설명                |
| ------------ | ------------------- |
| AEB          | 자동 긴급 제동 발생 |
| CONSTRUCTION | 공사 구간 감지      |

### 이벤트 목록

![이벤트 목록](images/event-history/event-list.png)

목록의 각 행에는 다음 정보가 표시됩니다.

| 열                | 내용                                |
| ----------------- | ----------------------------------- |
| <nobr>날짜</nobr> | 이벤트 발생 일시                    |
| <nobr>유형</nobr> | 이벤트 종류 (AEB / CONSTRUCTION 등) |
| <nobr>차량</nobr> | 이벤트 발생 차량 이름               |
| <nobr>지역</nobr> | 이벤트 발생 지역 이름               |

행을 클릭하면 다음 두 가지 동작이 함께 일어납니다.

1. 지도가 해당 이벤트가 발생한 지역으로 이동합니다.
2. 이벤트 상세 오버레이가 표시됩니다. 오버레이에서는 이벤트 발생 시점의 영상과 세부 정보를 확인할 수 있습니다.

![이벤트 상세 오버레이](images/event-history/event-detail-overlay.png)

## 원격 명령 탭

차량에 발송된 원격 명령 요청 이력을 조회합니다.

### 필터

![원격 명령 필터](images/event-history/remote-cmd-filter.png)

기간·차량·지역 조건으로 필터링할 수 있습니다.
이벤트 유형 필터는 이 탭에서는 제공되지 않습니다.

### 원격 명령 목록

![원격 명령 목록](images/event-history/remote-cmd-list.png)

| 열   | 내용                |
| ---- | ------------------- |
| 날짜 | 원격 명령 발생 일시 |
| 유형 | 명령 유형           |
| 차량 | 명령 대상 차량 이름 |
| 지역 | 명령 발생 지역 이름 |

행을 클릭하면 지도가 해당 지역으로 이동합니다.
