# 차량 제어기 상태 및 버전 정보 (`/sw-versions`)

마스터 컴퍼니 소속 유저 전용 페이지. 사이드바 차량 목록 우측 상단 아이콘을 클릭해 새 창으로 진입.

---

## 주요 기능

### 버전 정보 테이블

모든 차량의 제어기 버전을 한 화면에서 조회.

| 컬럼                                                    | 설명                                                                |
| ------------------------------------------------------- | ------------------------------------------------------------------- |
| Vehicle Name                                            | 운행 중이면 좌측에 초록 선, 미운행이면 회색 선                      |
| Vehicle ID                                              | 차량 식별 ID                                                        |
| Status                                                  | 운행 중인 차량만 표시. 정상이면 초록, 오류 발생 시 빨간 점          |
| ACU SW / MAP / AI Framework / E2E / TCU-M / TCU-S / CMU | 각 제어기 버전                                                      |
| CONFIG                                                  | 운행 중 차량의 실시간 설정 버전. 서버 설정과 다르면 빨간색으로 표시 |

- Status 빨간 점 클릭 시 오류 코드 상세 팝오버 표시

### 정렬

- 모든 컬럼 오름차순 → 내림차순 → 해제 순으로 정렬 가능
- 정렬 가능 여부는 헤더 아이콘으로 항상 표시, 라벨 호버 시 효과 발생
- 기본 정렬: Vehicle ID 오름차순

### 검색 / 필터

- 우측 상단 돋보기 아이콘 클릭 시 검색 필드 펼침 (차량명·ID)
- 스위치로 운행 중인 차량만 보기 전환 가능

### 새로고침

- 1분마다 자동 새로고침
- 우측 하단 고정 영역에 마지막 업데이트 시각 표시 및 수동 새로고침 버튼 제공

### 접근 제한

- 마스터 컴퍼니 소속 유저만 접근 가능 (페이지 및 진입 버튼 모두)
- 비인가 접근 시 401 페이지로 리다이렉트
