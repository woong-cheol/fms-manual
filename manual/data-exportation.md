# 데이터 추출

## 개요

차량 운행 기록과 원격명령 발생 횟수를 조회하고 CSV 파일로 내보낼 수 있는 기능입니다.
세 가지 탭으로 구성되며, 각 탭마다 별도의 조건으로 필터링하고 결과를 다운로드할 수 있습니다.

---

## 진입 방법

좌측 사이드바에서 **데이터 추출 아이콘**을 클릭합니다.

![데이터 추출 아이콘](images/data-exportation/entry-button.png)

같은 아이콘을 다시 클릭하면 패널이 닫힙니다.

---

## 화면 구성

| 탭              | 내용                                       |
| --------------- | ------------------------------------------ |
| 차량별 주행기록 | 차량별 자율·수동 주행 거리와 시간 조회     |
| 원격명령 횟수   | 차량별 원격명령 레벨·원인별 발생 횟수 조회 |
| 시간별 주행기록 | 운행 단위(코스)별 세부 주행기록 조회       |

각 탭 하단에는 현재 조회된 데이터를 **CSV 파일로 내보내기** 버튼이 있습니다.

---

## 차량별 주행기록 탭

차량별로 집계된 주행 거리와 시간을 조회합니다.

### 필터

![차량별 주행기록 필터](images/data-exportation/driving-stats-filter.png)

| 필터 항목 | 설명                                                 |
| --------- | ---------------------------------------------------- |
| 기간      | 시작일과 종료일을 달력으로 선택 (기본값: 최근 1개월) |
| 차량      | 특정 차량을 선택해 해당 차량만 조회                  |

조건을 변경하면 테이블이 자동으로 갱신됩니다.

### 데이터 항목

![차량별 주행기록 테이블](images/data-exportation/driving-stats-table.png)

| 항목                       | 설명                                             |
| -------------------------- | ------------------------------------------------ |
| 자율 거리                  | 자율주행 구간의 누적 주행거리 (km)               |
| 자율 시간                  | 자율주행 구간의 누적 주행시간 (분)               |
| 수동(자율주행 가능) 거리   | 자율주행 가능 상태에서 운전자가 수동 운행한 거리 |
| 수동(자율주행 가능) 시간   | 자율주행 가능 상태에서 수동 운행한 시간          |
| 수동(자율주행 불가능) 거리 | 자율주행 불가 상태에서 수동 운행한 거리          |
| 수동(자율주행 불가능) 시간 | 자율주행 불가 상태에서 수동 운행한 시간          |
| 수동(스쿨존/실버존) 거리   | 스쿨존·실버존 구간의 수동 운행 거리              |
| 수동(스쿨존/실버존) 시간   | 스쿨존·실버존 구간의 수동 운행 시간              |
| 수동(센서에러) 거리        | 센서 오류로 인해 수동 전환된 구간의 거리         |
| 수동(센서에러) 시간        | 센서 오류로 인해 수동 전환된 구간의 시간         |

테이블 열 헤더를 클릭하면 해당 열 기준으로 정렬됩니다.

### CSV 내보내기

테이블 우측 하단의 **CSV 내보내기** 버튼을 클릭하면 현재 표시된 데이터를 파일로 저장합니다.
정렬 순서가 반영된 상태로 내보내집니다.

---

## 원격명령 횟수 탭

차량별로 원격명령 요청 횟수를 레벨·원인별로 집계한 데이터를 조회합니다.

### 필터

기간과 차량을 선택해 조회 조건을 설정합니다.
조건을 변경하면 테이블이 자동으로 갱신됩니다.

![원격명령 횟수 필터](images/data-exportation/remote-cmd-filter.png)

### 데이터 항목

![원격명령 횟수 테이블](images/data-exportation/remote-cmd-table.png)

Lv.1~Lv.4 각 레벨별 원인 항목의 발생 횟수가 열로 표시됩니다.
각 레벨의 세부 원인은 [대시보드 — 운행 통계 차트](/manual/dashboard#운행-통계-차트-원격명령-원인) 항목을 참고하세요.

열 우측 상단의 **?** 아이콘을 클릭하면 각 원인 항목에 대한 설명 팝오버가 표시됩니다.

### CSV 내보내기

테이블 우측 하단의 **CSV 내보내기** 버튼으로 데이터를 파일로 저장합니다.

---

## 시간별 주행기록 탭

운행 단위(코스 출발~도착)별로 세분화된 주행기록을 조회합니다.
차량별 주행기록 탭과 달리 개별 운행 단위로 기록이 분리되어 표시됩니다.

### 필터

![시간별 주행기록 필터](images/data-exportation/hourly-filter.png)

| 필터 항목 | 설명                                                      |
| --------- | --------------------------------------------------------- |
| 기간      | 시작일과 종료일을 달력으로 선택 (기본값: 최근 1개월)      |
| 차량      | 특정 차량을 선택 (기간과 차량을 모두 선택해야 조회됩니다) |

> 기간과 차량을 모두 선택하지 않으면 데이터가 조회되지 않습니다.

### 데이터 항목

![시간별 주행기록 테이블](images/data-exportation/hourly-table.png)

| 항목                              | 설명                           |
| --------------------------------- | ------------------------------ |
| 운행 시작 시각                    | 해당 운행 단위의 출발 시각     |
| 차량 ID / 차량명                  | 운행 차량 정보                 |
| 지역 ID / 지역명                  | 운행 지역 정보                 |
| 코스 ID / 코스명                  | 운행한 경로(코스) 정보         |
| 자율 거리 / 시간                  | 자율주행 구간 거리 및 시간     |
| 수동(자율주행 가능) 거리 / 시간   | 자율주행 가능 상태의 수동 운행 |
| 수동(자율주행 불가능) 거리 / 시간 | 자율주행 불가 상태의 수동 운행 |
| 수동(스쿨존/실버존) 거리 / 시간   | 스쿨존·실버존 수동 운행        |
| 수동(센서에러) 거리 / 시간        | 센서 오류로 인한 수동 전환     |

### CSV 내보내기

테이블 우측 하단의 **CSV 내보내기** 버튼으로 데이터를 파일로 저장합니다.
