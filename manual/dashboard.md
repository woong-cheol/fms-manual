# 대시보드

## 개요

대시보드는 차량 운행 통계를 한눈에 파악할 수 있는 화면입니다.
지정된 기간과 차량·지역 조건에 따라 주행거리, 원격 명령, 원격 제어 현황을 시각적으로 제공합니다.

---

## 화면 구성

| 영역           | 설명                                          |
| -------------- | --------------------------------------------- |
| 필터           | 조회 기간, 차량, 지역 조건 설정               |
| 요약 카드      | 주행거리 / 주행시간 / 이벤트 / 원격 요청 합계 |
| 주행거리 차트  | 기간별 자동·수동 주행거리 추이 (라인 차트)    |
| 운행 통계 차트 | 원격 명령·제어를 레벨별로 집계한 바 차트      |
| Top 5 차량     | 원격 명령/제어 횟수 기준 상위 5개 차량        |
| Top 5 지역     | 원격 명령/제어 횟수 기준 상위 5개 지역        |

---

## 필터 사용법

### 기간 선택

화면 상단의 기간 버튼으로 조회 범위를 변경합니다.

- **최근 14일** — 일별 데이터를 표시
- **최근 3달** — 월별 데이터를 표시
- **최근 1년** — 월별 데이터를 표시

### 차량·지역 선택

필터 버튼을 클릭하면 차량과 지역을 복수 선택할 수 있습니다.
선택하지 않으면 전체 차량·지역을 기준으로 집계됩니다.

---

## 주행거리 차트

선택한 기간 동안의 **자동 주행거리**와 **수동 주행거리**를 라인 차트로 보여줍니다.

- 차트의 각 점에 마우스를 올리면 해당 날짜/월의 상세 수치를 툴팁으로 확인할 수 있습니다.

---

## 운행 통계 차트

원격 명령 또는 원격 제어 발생 건수를 **레벨(Lv.1 ~ Lv.4)** 별로 집계한 바 차트입니다.

### 레벨 기준

| 레벨 | 설명                      |
| ---- | ------------------------- |
| Lv.1 | 자율주행 중 일시적인 개입 |
| Lv.2 | 짧은 구간 수동 운행       |
| Lv.3 | 긴 구간 수동 운행         |
| Lv.4 | 운행 불가 수준의 개입     |

### 원인 툴팁

바 차트의 막대에 마우스를 올리면 해당 기간의 **원인별 발생 횟수**를 상세하게 확인할 수 있습니다.

---

## Top 5 차량 / 지역

필터 기간 내 원격 명령 또는 원격 제어 횟수가 가장 많은 상위 5개 항목을 표시합니다.

- **원격 명령 Top5** — 차량별 / 지역별
- **원격 제어 Top5** — 차량별 / 지역별
