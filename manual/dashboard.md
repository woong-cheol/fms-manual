# 대시보드

## 개요

대시보드는 차량 운행 통계를 한눈에 파악할 수 있는 화면입니다.
지정한 기간·차량·지역 조건에 따라 주행거리, 이벤트, 원격 명령·제어 현황을 다양한 차트와 수치로 시각화합니다.

대시보드는 두 개의 탭으로 구성됩니다.

| 탭        | 내용                                       |
| --------- | ------------------------------------------ |
| 운행 통계 | 주행거리, 이벤트, 원격 명령·제어 종합 현황 |
| 원격명령  | 원격명령 요청 건수 및 원인 상세 분석       |

---

## 진입 방법

지도 화면 우측에 위치한 플로팅 버튼 중 **대시보드 버튼**을 클릭합니다.

![대시보드 버튼 위치](images/dashboard/entry-button.png)

버튼을 다시 클릭하면 대시보드가 닫힙니다.

![대시보드 전체 화면](images/dashboard/overview.png)

| 영역               | 설명                                                |
| ------------------ | --------------------------------------------------- |
| 탭 선택            | 운행 통계 / 원격명령 탭 전환                        |
| 필터               | 조회 기간·차량·지역 조건 설정 및 적용 칩 표시       |
| 요약 카드          | 주행거리 / 주행시간 / 이벤트 / 원격 요청 합계 수치  |
| Top 5 그래프       | 원격 명령·제어 횟수 기준 상위 5개 차량·지역 바 차트 |

| 원격명령 원인 차트 | 레벨별(Lv.1~Lv.4) 원격명령 원인 바 차트             |

| 상위 3 차량 차트   | 누적 주행거리 기준 상위 3개 차량 비교 라인 차트     |

## 필터 사용법

화면 상단 좌측의 **필터 아이콘(≡)** 을 클릭하면 필터 팝오버가 열립니다.

![필터 팝오버](images/dashboard/filter-popover.png)

팝오버 안에서 기간·지역·차량 조건을 설정한 뒤 **조회** 버튼을 눌러야 데이터가 갱신됩니다.
모든 조건을 초기값으로 되돌리려면 **선택 초기화** 링크를 클릭합니다.

### 기간 선택

기간 필드를 클릭하면 달력이 열립니다.
시작일을 먼저 클릭하고, 이어서 종료일을 클릭하면 범위가 지정됩니다.

- 기본값은 **오늘 기준 최근 3개월**입니다.
- 기간에 따라 X축 단위가 자동으로 조정됩니다 (일별·주별·월별).

### 지역 선택

조회할 지역을 하나 이상 선택할 수 있습니다.
선택하지 않으면 전체 지역을 기준으로 집계됩니다.

### 차량 선택

조회할 차량을 하나 이상 선택할 수 있습니다.
선택하지 않으면 전체 차량을 기준으로 집계됩니다.

### 적용된 필터 확인

조회 후 현재 적용된 조건이 필터 아이콘 옆에 **칩(Chip)** 형태로 표시됩니다.
기간 칩은 항상 표시되고, 지역·차량은 선택한 경우에만 나타납니다.

![적용된 필터 칩](images/dashboard/filter-chips.png)

## 요약 카드

필터 조건 기간 동안의 전체 합계를 네 가지 수치 카드로 표시합니다.

![요약 카드](images/dashboard/summary-cards.png)

| 카드          | 설명                                                 |
| ------------- | ---------------------------------------------------- |
| 주행거리 [KM] | 조회 기간 내 전체 누적 주행거리                      |
| 주행시간 [H]  | 조회 기간 내 전체 누적 주행시간                      |
| 이벤트        | AEB·불법 주정차·공사구간 회피 등 이벤트 발생 총 건수 |
| 원격 요청     | 원격 명령 및 원격 제어 요청 총 건수                  |

---

## Top 5 차량 / 지역

필터 기간 내 원격 명령 또는 원격 제어 요청 횟수가 가장 많은 상위 5개 항목을 바 차트로 보여줍니다.

![Top5 차량·지역](images/dashboard/top5.png)

총 네 개의 그래프가 제공됩니다.

| 그래프                 | 기준                       |
| ---------------------- | -------------------------- |
| 원격명령 Top5 — 차량별 | 차량별 원격 명령 요청 횟수 |
| 원격명령 Top5 — 지역별 | 지역별 원격 명령 요청 횟수 |
| 원격제어 Top5 — 차량별 | 차량별 원격 제어 요청 횟수 |
| 원격제어 Top5 — 지역별 | 지역별 원격 제어 요청 횟수 |

각 막대에 마우스를 올리면 해당 차량 또는 지역의 정확한 횟수를 툴팁으로 확인할 수 있습니다.
데이터가 없는 경우 "데이터가 없습니다" 메시지가 표시됩니다.

## 이벤트 유형 차트

조회 기간 동안 발생한 이벤트를 유형별로 집계한 바 차트입니다.

![이벤트 유형 차트](images/dashboard/event-type-chart.png)

| 유형          | 설명                        |
| ------------- | --------------------------- |
| AEB           | 자동 긴급 제동 발생 건수    |
| 불법 주정차   | 불법 주정차 감지 건수       |
| 공사구간 회피 | 공사 구간 감지 및 회피 건수 |

## 운행 통계 차트 (원격명령 원인)

원격 명령 요청 건수를 **레벨(Lv.1 ~ Lv.4)** 별로 집계한 바 차트입니다.
각 막대는 기간별 레벨 분포를 색상으로 구분하여 표시합니다.

![운행 통계 차트](images/dashboard/stats-chart.png)

### 레벨 기준

| 레벨 | 색상   | 설명                      |
| ---- | ------ | ------------------------- |
| Lv.1 | 파란색 | 자율주행 중 일시적인 개입 |
| Lv.2 | 청록색 | 짧은 구간 수동 운행       |
| Lv.3 | 주황색 | 긴 구간 수동 운행         |
| Lv.4 | 보라색 | 운행 불가 수준의 개입     |

### 원인 툴팁

막대에 마우스를 올리면 해당 기간의 **레벨별 발생 횟수**와 **세부 원인별 횟수**를 함께 확인할 수 있습니다.

![원인 툴팁](images/dashboard/stats-chart-tooltip.png)

#### Lv.1 세부 원인

| 원인                  | 설명                             |
| --------------------- | -------------------------------- |
| 포켓 차로 진입 전     | 포켓 차로 진입 전 일시적 개입    |
| 교차로 우회전 진입 전 | 교차로 우회전 직전 개입          |
| 톨게이트 진입 전      | 톨게이트 통과를 위한 개입        |
| 연속 차로 변경 필요   | 짧은 거리 내 여러 차로 변경 필요 |
| 정류장 차로 진입 실패 | 버스 정류장 차로 진입 실패       |
| 고속 차로 변경        | 고속 상황에서의 차로 변경 개입   |
| 정체 중 차로 변경     | 정체 구간에서의 차로 변경 개입   |

#### Lv.2 세부 원인

| 원인                           | 설명                                |
| ------------------------------ | ----------------------------------- |

| 회전교차로 진입 어려움         | 회전교차로 진입 판단 실패           |
| 주정차 차량으로 유턴 어려움    | 주정차 차량으로 유턴 공간 부족      |
| 비보호 좌회전 어려움           | 비보호 좌회전 타이밍 판단 실패      |
| 정류장 후 연속 차로 변경       | 정류장 출발 후 연속 차로 변경 필요  |

#### Lv.3 세부 원인

| 원인              | 설명                                        |
| ----------------- | ------------------------------------------- |

| --------------------------- | ------------------------------------------ |

| 원거리 정류장 활성화        | 너무 먼 거리에서 정류장이 활성화됨         |

## 주행거리 차트

조회 기간 동안의 **자동 주행거리**와 **수동 주행거리**를 시계열 라인 차트로 보여줍니다.

![주행거리 차트](images/dashboard/driving-distance-chart.png)

- **파란색 선**: 자동 주행거리 (자율주행 구간)
- **청록색 선**: 수동 주행거리 (운전자가 직접 운전한 구간)
- 각 점에 마우스를 올리면 해당 날짜·주·월의 정확한 거리(KM)를 툴팁으로 확인할 수 있습니다.
- 기간에 따라 X축이 일별·주별·월별로 자동 조정됩니다.

---

## 분포 차트 (산점도)

원격 명령 또는 원격 제어가 **어느 날짜**의 **몇 시**에 집중적으로 발생했는지 산점도로 시각화합니다.

![분포 차트](images/dashboard/scatter-chart.png)

- X축: 날짜
- Y축: 시간대 (0시~24시)
- 점 하나가 발생 건수 1회를 나타냅니다.
- 특정 시간대나 요일에 집중된 패턴을 빠르게 파악할 수 있습니다.

---

## 상위 3 차량 주행거리 차트

조회 기간 내 누적 주행거리가 가장 많은 **상위 3개 차량**의 주행거리 추이를 라인 차트로 비교합니다.

![상위 3 차량 차트](images/dashboard/top3-vehicles-chart.png)

- 세 가지 색상(파란색·청록색·보라색)으로 각 차량을 구분합니다.
- 범례에서 차량 이름을 확인할 수 있습니다.
- 각 점에 마우스를 올리면 해당 시점의 정확한 주행거리를 확인할 수 있습니다.
