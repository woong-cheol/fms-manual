# OVERVIEW

## 화면 구성

![전체 화면](images/overview/overview.png)

로그인 후 처음 표시되는 화면입니다. 전체 지도를 배경으로 운행 중인 차량의 실시간 위치를 확인하고, 각종 기능에 빠르게 접근할 수 있습니다.

화면은 크게 세 영역으로 구성됩니다.

| 영역                             | 위치                     | 설명                               |
| -------------------------------- | ------------------------ | ---------------------------------- |
| [좌측 사이드바](/manual/sidebar) | <nobr>화면 왼쪽</nobr>   | 주요 기능 진입 및 설정             |
| [지도 화면](/manual/map-view)    | <nobr>화면 중앙</nobr>   | 실시간 차량 위치 확인 및 지도 조작 |
| [대시보드](/manual/dashboard)    | <nobr>화면 오른쪽</nobr> | 차량 운행 통계 확인                |
