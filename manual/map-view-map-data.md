# 지도 레이어

## 개요

![지도 레이어 버튼 그룹](images/map-view-map-data/layer-buttons.png)

지도 위에 코스, 공사구간, LDM(동적 지도 데이터), 주행경로, 정류장 정보를 표시하거나 숨길 수 있습니다. 버튼은 각 지도 화면 우측에 표시되며, 지역 또는 차량 선택 여부에 따라 활성화됩니다.

---

## 코스

![코스 버튼 팝오버](images/map-view-map-data/course-popover.png)

해당 지역에 등록된 코스 목록을 팝오버로 표시합니다.

**활성화 조건**: 지역 선택 시

- 코스를 선택하면 해당 경로가 지도에 강조 표시됩니다.
- 같은 코스를 다시 클릭하면 선택이 해제됩니다.

![코스 표시 예시](images/map-view-map-data/course-on-map.png)

---

## 공사구간

![공사구간 팝오버](images/map-view-map-data/construction-popover.png)

공사구간 데이터를 날짜 범위로 조회하고 지도 표시 여부를 제어합니다.

**활성화 조건**: 지역 선택 시

버튼을 클릭하면 팝오버가 열립니다.

#### 팝오버 구성

| 영역               | 설명                                                                                                                                   |
| ------------------ | -------------------------------------------------------------------------------------------------------------------------------------- |
| 표시 / 숨기기 버튼 | 지도에 공사구간 아이콘 표시 여부를 토글합니다.                                                                                         |
| 날짜 범위 선택     | 시작일~종료일을 캘린더에서 선택한 뒤 **적용**을 누르면, 해당 기간의 공사구간 데이터를 지도에 표시하며 자동으로 표시 상태로 전환됩니다. |

![공사구간 표시 예시](images/map-view-map-data/construction-on-map.png)

#### 공사구간 아이콘 클릭 팝업

지도 위 공사구간 아이콘을 클릭하면 상세 팝업이 표시됩니다.

![공사구간 클릭 팝업](images/map-view-map-data/construction-event-popup.png)

| 항목      | 표시 형식                                                 |
| --------- | --------------------------------------------------------- |
| 차량명    | 텍스트                                                    |
| 발생 시각 | YY/MM/DD HH:mm:ss                                         |
| Type 배지 | 이벤트 유형 (주황색)                                      |
| 이미지    | 이벤트 촬영 이미지 (있을 경우). 클릭 시 전체화면으로 확대 |
| East      | UTM 동쪽 좌표                                             |
| North     | UTM 북쪽 좌표                                             |
| Speed     | 속도 (kph)                                                |
| AccLong   | 종방향 가속도 (m/s²)                                      |

---

## LDM (동적 지도 데이터)

![LDM 버튼 팝오버](images/map-view-map-data/ldm-popover.png)

동적 지도 데이터(LDM)를 날짜 범위로 조회하고 유형별로 표시하거나 숨깁니다.

**활성화 조건**: 지역 선택 시

버튼을 클릭하면 팝오버가 열립니다.

#### 팝오버 구성

| 영역             | 설명                                                                                                             |
| ---------------- | ---------------------------------------------------------------------------------------------------------------- |
| 유형 아이콘 토글 | AEB · 주정차 회피 · 공사구간 회피제어를 개별로 켜거나 끕니다. 해당 유형 데이터가 없으면 아이콘이 비활성화됩니다. |
| 날짜 범위 선택   | 시작일~종료일을 캘린더에서 선택한 뒤 **적용**을 누르면, 해당 기간의 LDM 데이터를 지도에 반영합니다.              |

| 유형              | 설명                                |
| ----------------- | ----------------------------------- |
| AEB               | 자동 긴급 제동 관련 동적 데이터     |
| 주정차 회피       | 주정차 차량 회피 관련 동적 데이터   |
| 공사구간 회피제어 | 공사구간 회피 제어 관련 동적 데이터 |

![LDM 표시 예시](images/map-view-map-data/ldm-on-map.png)

#### LDM 아이콘 클릭 팝업

지도 위 LDM 아이콘을 클릭하면 상세 팝업이 표시됩니다.

![LDM 클릭 팝업 (AEB)](images/map-view-map-data/ldm-event-popup-aeb.png)

| 항목      | 표시 형식                                  |
| --------- | ------------------------------------------ |
| 차량명    | 텍스트                                     |
| 발생 시각 | YY/MM/DD HH:mm:ss                          |
| Type 배지 | AEB · 주정차 회피 · 공사구간 회피 (주황색) |
| East      | UTM 동쪽 좌표                              |
| North     | UTM 북쪽 좌표                              |
| Azimuth   | 방위각 (도, °)                             |
| Altitude  | 고도 (m)                                   |

## 주행경로

![주행경로 표시 예시](images/map-view-map-data/route-on-map.png)

선택한 차량의 주행경로를 지도에 표시하거나 숨깁니다.

**활성화 조건**: 지역 선택 + 차량 선택 + 해당 차량에 경로 데이터 존재

세 조건이 모두 충족되지 않으면 버튼이 비활성화됩니다.

---

## 정류장

![정류장 표시 예시](images/map-view-map-data/stations-on-map.png)

선택한 차량이 운행하는 지역의 정류장 위치를 지도에 표시하거나 숨깁니다.

**활성화 조건**: 지역 선택 + 차량 선택 + 해당 지역에 정류장 데이터 존재

세 조건이 모두 충족되지 않으면 버튼이 비활성화됩니다.

#### 정류장 아이콘 클릭 팝업

지도 위 정류장 아이콘을 클릭하면 상세 팝업이 표시됩니다.

![정류장 클릭 팝업](images/map-view-map-data/station-popup.png)

| 항목          | 표시 형식                                  |
| ------------- | ------------------------------------------ |
| 정류장명      | 헤더 텍스트                                |
| 정류장 ID     | 배지                                       |
| East          | UTM 동쪽 좌표                              |
| North         | UTM 북쪽 좌표                              |
| 좌표 복사하기 | 클릭 시 East, North 좌표를 클립보드에 복사 |
