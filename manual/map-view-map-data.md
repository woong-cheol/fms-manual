# 지도 레이어

## 개요

![지도 레이어 버튼 그룹](images/map-view-map-data/layer-buttons.png)

지도 위에 코스, 공사구간, LDM(동적 지도 데이터), 주행경로, 정류장 정보를 표시하거나 숨길 수 있습니다. 버튼은 각 지도 화면 우측에 표시되며, 지역 또는 차량 선택 여부에 따라 활성화됩니다.

---

## 코스

![코스 버튼 팝오버](images/map-view-map-data/course-popover.png)

해당 지역에 등록된 코스 목록을 팝오버로 표시합니다.

**활성화 조건**: 지역 선택 시

- 코스를 선택하면 해당 경로가 지도에 강조 표시됩니다.
- 같은 코스를 다시 클릭하면 선택이 해제됩니다.

![코스 표시 예시](images/map-view-map-data/course-on-map.png)

---

## 공사구간

![공사구간 표시 예시](images/map-view-map-data/construction-on-map.png)

지도에 공사구간 표시를 켜거나 끕니다.

**활성화 조건**: 지역 선택 시

활성화 시 버튼이 선택 상태로 표시되며, 지도에 공사구간 위치가 강조됩니다.

---

## LDM (동적 지도 데이터)

![LDM 버튼 팝오버](images/map-view-map-data/ldm-popover.png)

동적 지도 데이터(LDM)를 유형별로 표시하거나 숨깁니다.

**활성화 조건**: 지역 선택 시

| 유형                           | 설명                                |
| ------------------------------ | ----------------------------------- |
| AEB                            | 자동 긴급 제동 관련 동적 데이터     |
| <nobr>주정차 회피</nobr>       | 주정차 차량 회피 관련 동적 데이터   |
| <nobr>공사구간 회피제어</nobr> | 공사구간 회피 제어 관련 동적 데이터 |

각 유형을 개별로 토글할 수 있습니다. 해당 유형의 데이터가 없으면 버튼이 비활성화됩니다.

![LDM 표시 예시](images/map-view-map-data/ldm-on-map.png)

---

## 주행경로

![주행경로 표시 예시](images/map-view-map-data/route-on-map.png)

선택한 차량의 주행경로를 지도에 표시하거나 숨깁니다.

**활성화 조건**: 지역 선택 + 차량 선택 + 해당 차량에 경로 데이터 존재

세 조건이 모두 충족되지 않으면 버튼이 비활성화됩니다.

---

## 정류장

![정류장 표시 예시](images/map-view-map-data/stations-on-map.png)

선택한 차량이 운행하는 지역의 정류장 위치를 지도에 표시하거나 숨깁니다.

**활성화 조건**: 지역 선택 + 차량 선택 + 해당 지역에 정류장 데이터 존재

세 조건이 모두 충족되지 않으면 버튼이 비활성화됩니다.
