# 화면 분할

## 개요

지도 화면을 여러 개로 나눠 동시에 다른 지역이나 차량을 확인할 수 있는 기능입니다.

---

## 진입 방법

![뷰 버튼](images/map-view-screen-split/view-button.png)

지도 화면 우측 상단의 **뷰 버튼**을 클릭합니다. 클릭하면 분할 방식을 선택하는 팝오버가 열립니다.

![분할 선택 팝오버](images/map-view-screen-split/split-popover.png)

---

## 분할 방식

![화면 분할 예시 — 2×2](images/map-view-screen-split/split-2x2.png)

| 방식 | 화면 수 | 설명                                    |
| ---- | ------- | --------------------------------------- |
| 1×1  | 1개     | 지도 한 개를 전체 화면으로 표시         |
| 1×2  | 2개     | 좌우로 2개의 지도를 나란히 표시         |
| 1:2  | 3개     | 왼쪽 큰 지도 1개 + 오른쪽 작은 지도 2개 |
| 2×2  | 4개     | 2행 2열로 4개의 지도 표시               |
| 2×3  | 6개     | 2행 3열로 6개의 지도 표시               |

---

## 다중 화면 조작

![다중 화면 — 활성 화면 선택 상태](images/map-view-screen-split/multi-screen-active.png)

다중 화면 모드에서 지도 화면을 클릭하면 해당 화면이 활성화됩니다.

- 활성화된 화면에만 지도별 동적 버튼이 표시됩니다.
- 각 지도 화면은 독립적으로 지역·차량을 선택하고 표시 옵션을 설정할 수 있습니다.
